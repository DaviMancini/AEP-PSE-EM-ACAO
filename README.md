# PSE EM AÇÃO

## Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola

Projeto desenvolvido para a Atividade de Estudo Programada (AEP) do 2º semestre de 2026 do curso de Engenharia de Software da Universidade Cesumar - UniCesumar.

## Integrantes

- Davi Mancini Faustino Da Silva
- Nicolas Alexandre
- Davi Pena Justino

## Objetivo do projeto

Desenvolver uma aplicação em linguagem C, executada em terminal, para apoiar o planejamento, o cadastro, a consulta e o acompanhamento de ações coletivas do Programa Saúde na Escola (PSE).

## Funcionalidades previstas

- Cadastro de ações do PSE
- Listagem das ações cadastradas
- Pesquisa por código, escola ou tema
- Atualização da situação da ação
- Registro da quantidade efetiva de participantes
- Geração de resumo das ações e participação
- Validação de dados informados pelo usuário

## Tecnologias

- Linguagem C
- GitHub
- Aplicação executada em terminal

## Estrutura do projeto

- `documentacao/` - documentos, fluxogramas e materiais da AEP
- `src/` - código-fonte em linguagem C
- `README.md` - informações gerais do projeto
